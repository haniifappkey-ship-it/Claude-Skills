# Skills
Skills are folders of instructions, scripts, and resources that Claude loads dynamically to improve performance on specialized tasks. Skills teach Claude how to complete specific tasks in a repeatable way, whether that's creating documents with your company's brand guidelines, analyzing data using your organization's specific workflows, or automating personal tasks.

For more information, check out:
- [What are skills?](https://support.claude.com/en/articles/12512176-what-are-skills)
- [Using skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude)
- [How to create custom skills](https://support.claude.com/en/articles/12512198-creating-custom-skills)
- [Equipping agents for the real world with Agent Skills](https://anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills)

# Claude-Skills ⚡

This repository contains custom, plug-and-play skills designed to showcase what's possible with Claude's skills system. These skills range from daily productivity tools and language assistants to specialized educational and travel guides. 

Each skill is self-contained and ready to use, helping you automate daily workflows, learn new topics, or get instant assistance. Browse through the available skills below to supercharge your Claude AI experience!

---

## 🚀 Key Features
* **Ready-to-Use:** Just copy the instructions or load them into your Claude Project Knowledge base.
* **Versatile:** Covers practical workflows, education, coding, and lifestyle guides.
* **Optimized Performance:** Crafted with tailored instructions to ensure Claude delivers precise, high-quality results.

## 🛠️ How to Use
1. **Browse:** Check the [Available Skills](#-available-skills) list below and navigate to the skill's folder.
2. **Copy:** Open the `SKILL.md` or prompt file inside the folder and copy the text.
3. **Run:** Paste it directly into your Claude AI chat or add it to your Claude Project Knowledge base to activate the skill instantly.
